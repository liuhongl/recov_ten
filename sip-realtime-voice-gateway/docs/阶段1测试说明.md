# 阶段 1 测试说明

## 目标

验证 `sip-realtime-voice-gateway/` 可以作为独立项目启动，不依赖 TEN。

本阶段不接 FreeSWITCH，不接实时语音模型。

## 测试项

1. 配置文件可加载。
2. 环境变量可以覆盖配置。
3. 服务可启动。
4. `/health` 返回健康状态。
5. `/ready` 返回脱敏后的运行配置。
6. 单元测试通过。

## 命令

```powershell
cd sip-realtime-voice-gateway
python -m pytest
python -m app.main --config configs/local.example.toml --check-config
python -m app.main --config configs/local.example.toml
```

健康检查：

```powershell
Invoke-RestMethod http://127.0.0.1:9100/health
Invoke-RestMethod http://127.0.0.1:9100/ready
```

## 通过标准

- `python -m pytest` 成功。
- `--check-config` 能输出配置 JSON。
- `/health` 返回 `{"status": "ok"}`。
- `/ready` 不输出任何 API key。
